# Lessons Learned Project

This project uses HTML and CSS for the Fundamentals module of Trybe's Full Stack Web Development course. This website presents some of the skills I learned in the course, skills I'd like to acquire, and information about my current level of these skills.


---


### Linter

This project used the "Eslint" linter installed by Trybe. To run the linter locally, run:

```bash
npm run lint:styles
```


### Automatic evaluator

The project requirements were evaluated using Cypress installed by Trybe. To run the automatic evaluator, run one of the following commands locally:

```bash
npm test
```

***or***

```bash
npm run cypress:open
```
